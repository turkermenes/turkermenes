### 📌 Featured Projects

#### 🕵️ [Casus Aramızda](https://casusaramizda.online)

A real-time multiplayer social deduction game for 3–12 players, live at [casusaramizda.online](https://casusaramizda.online). Everyone gets the same secret word except one player: the spy. Players give clues that are neither too obvious nor too vague, then vote to find the spy, while the spy tries to guess the word before getting caught.

- 🎮 Private rooms via code or link, plus a **Quick Play** mode with automatic matchmaking that starts when the room fills
- 🗳️ Multiple game modes: timed or round-based voting, and free voice play with instant accusations
- 🏆 Live scoring system with round results

**Tech**

- **Backend:** Java 21, Spring Boot 4, Spring WebSocket + STOMP for real-time communication
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS 4
- **Testing:** JUnit 5, Mockito, MockMvc, integration tests with a real STOMP client · Vitest, Testing Library
- **Deployment:** Multi-stage Docker image on Render with a custom domain · alternative setup with Docker Compose + Caddy

> 🔒 Source code is private. Happy to walk through it on request.
